# 전시관 예시 삽화

사용 도구: 기본 내장 `image_gen` 도구. CLI/API 대체 경로는 사용하지 않았습니다.

학생 제출물을 대신하는 자료가 아니라, 데모 및 전시 안내용으로 생성한 허구의 그림입니다. 모든 인물과 풍경은 문학적 상상이며 원작의 확정적 묘사를 증명하지 않습니다. 실제 학생이 올린 사진은 변경하지 않습니다.

웹용 최종 파일은 원본 구도를 유지한 WebP 형식으로 프로젝트에 저장했습니다.

- `public/art/literary-landscape.webp` — 배경과 사건 안내 그림
- `public/art/literary-girl.webp` — 적극적이고 다정한 해석
- `public/art/literary-boy.webp` — 조심스럽고 내성적인 해석
- `public/art/literary-girl-reserved.webp` — 고집스럽고 감정을 감춘 해석
- `public/art/literary-boy-defiant.webp` — 충동적이고 자존심이 상한 해석

아래는 생성에 사용한 최종 프롬프트 원문입니다.
